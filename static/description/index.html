Unified Nepal Payment Gateway Suite for Odoo 18

Accept Nepalese Rupee (NPR) online payments across Odoo eCommerce, Sales Orders, Invoices, and Customer Portal using eSewa (ePay v2), Khalti by IME (KPG-2), and ConnectIPS (NCHL) — engineered with strict cryptography, server-to-server verification, and 46 automated tests.

eSewa (ePay v2)

Base64 HMAC-SHA256 request & callback signature verification using constant-time comparison, mandatory signed_field_names checks, and server-to-server Status Check API verification.

Khalti by IME (KPG-2)

Server-to-server Initiate & Lookup REST APIs (Authorization: Key), exact paisa integer math, immutable pidx SQL unique binding, and strict redirect host whitelisting.

ConnectIPS (NCHL)

SHA256withRSA digital signing directly from uploaded .pfx (PKCS#12) or .pem private keys, built-in key self-test button, and HTTP Basic Auth validatetxn confirmation.

Seamless Odoo 18 Checkout Experience

All three Nepali payment methods appear natively inside Odoo eCommerce Checkout, Portal Invoices, and Payment Links — with built-in Local Simulation and Official UAT Sandbox modes.

Production-Grade Security & Reliability

  • Safe Default Install: Providers install Disabled & Unpublished so production sites never expose demo routes.
  • Replay Protection: SQL UNIQUE constraints on gateway TXN IDs & immutable Khalti pidx.
  • Race-Condition Safe: PostgreSQL FOR UPDATE NOWAIT row locking + per-callback DB savepoints.
  • Exact Financial Precision: Decimal rounding, strict NPR enforcement, fail-closed S2S checks.
  • Abandoned-Browser Recovery: Automatic 15-minute reconciliation cron polls pending UAT/Live payments.
  • Thoroughly Tested: 46 automated unit, crypto, white-box, grey-box, black-box & HTTP tests.

Quick Setup Guide

  1. Install Nepal Wallets from Apps — all three providers appear automatically under Configuration → Payment Providers.
  2. Activate NPR currency (under Invoicing → Configuration → Currencies) and set your Company or Website Pricelist to NPR.
  3. Open each provider, choose Test Mode (Local Interactive Simulation or Official Sandbox / UAT) or Enabled (Live), enter your credentials, and click Published.
